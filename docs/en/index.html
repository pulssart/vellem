The request

Plan a family outing for Saturday.

Copy prompt
Plan a family outing for Saturday.

Ask where we are starting, the ages, budget and maximum travel time. Find a free slot in the family Google Calendar I specify. Check venue websites for opening times on that date, admission for the whole family and booking requirements.

Suggest three different outings, including one indoors. Give a departure time, time on site and estimated total cost for each. Pick the best fit for our constraints and explain why in one sentence.

Cite the sources you consulted and include links when available. If a source is inaccessible or information is missing, say so. If nothing matches, tell me before sending anything.

Send the result to Vellem in Markdown using the send_output MCP tool. Give it a title that names the subject and set folder_name to “Personal”. Confirm once Vellem accepts it.

The result in Vellem

Saturday in the forest

  • A 6 km loop (about two hours) with the kids.
  • Picnic spot, weather and what to pack.

The request

Compare these two bathroom renovation quotes.

Copy prompt
Compare these two bathroom renovation quotes.

Ask for both quotes or the Gmail threads where they can be found. Match the scope, quantity, materials, tax-inclusive price and timeline for each line. Check travel, removal, disposal and finishing costs where relevant to the job.

Explain the price difference. Mark missing information as “unspecified” and distinguish optional extras from included work. End with three concrete questions I could send to the contractors before deciding.

Cite the sources you consulted and include links when available. If a source is inaccessible or information is missing, say so. If nothing matches, tell me before sending anything.

Send the result to Vellem in Markdown using the send_output MCP tool. Give it a title that names the subject and set folder_name to “Personal”. Confirm once Vellem accepts it.

The result in Vellem

Two quotes for the same room

  • The first includes removing the tiles. The second lists it as an extra.
  • Before choosing, ask whether either quote covers waste removal.

Prepare the sign-up flow for a design review.

Use the Notion spec and related Linear issues for the feature I name. If the feature is unclear, ask which one to review.

Prepare an agenda for the design review. For each user flow, identify the states the spec covers and any gaps in empty, loading or error states. Separate decisions already made from questions that need an answer, and link each question to its source.
