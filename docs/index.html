Why give your agents a notebook?

Every session with Claude or Codex ends with research, plans, decisions, code reviews — that vanish when the window closes. Vellem makes that work persist in a place you own. A real macOS app. Searchable. Foldered. Yours forever.

🤖 MCP-native, not bolted on

Vellem ships its own MCP server. 14 tools: add notes, todo lists, daily logs, folders, full-text search. Your agent doesn't ask permission — it just writes.

📁 One folder per agent

Claude writes to Claude. Codex to Codex. Smart folders out of the box. You always know who said what.

👀 You stay the reader

While your agents fill the database, you keep the beautiful native UI: menu bar capture, global hotkey, widgets, Today view, Markdown rendering with interactive todos.

🔒 Local-first, private

Everything lives on your Mac. No cloud, no sync server, no telemetry. Apple App Group container, NSFileCoordinator. Your agents' work never leaves your machine.

The MCP tools inside Vellem

Vellem gives agents a small, practical toolkit for memory. They can write, retrieve, update, and organize notes without asking you to copy text between windows.

Capture

add_note

Create a Markdown note, set an optional title, and place it in a folder by name or id.

append_to_daily

Add a snippet to today's daily note. If today's note does not exist yet, Vellem creates it.

create_todo_list

Turn a list of tasks into a proper Vellem note with interactive Markdown checkboxes.

add_todo

Add one task to an existing note, checked or unchecked, without rewriting the whole note.

Read and search

list_notes

Return recent notes with ids, titles, previews, note type, and update dates.

search_notes

Search note titles and bodies, case insensitive, with a controllable result limit.

get_note

Fetch the full content of a note by id when an agent needs exact context.

Edit

update_note

Replace a note body with a new Markdown version when the agent has a better draft.

delete_note

Remove a note by id when something was captured by mistake.

Organize

list_folders

List every folder, including ids, names, creation dates, and note counts.

create_folder

Create a folder by name, or reuse the existing one if it is already there.

delete_folder

Delete a folder while keeping its notes. The notes move back to the root.

set_folder_color

Set a folder color, or clear it, using the same palette as the app.

move_note

Move a note into a folder by id or name, create the folder if needed, or remove the note from its folder.

Plug it into Claude in 10 seconds

After installing Vellem, add this to claude_desktop_config.json and restart Claude:

{
  "mcpServers": {
    "vellem": {
      "command": "/Applications/Vellem.app/Contents/Resources/vellem-mcp"
    }
  }
}

Claude can now say "I'll save that report to Vellem" — and actually do it. Same idea for Codex, or any MCP client.

Install Vellem

  1. Click Download for macOS above.
  2. Open the Vellem-x.y.z.dmg file.
  3. Drag Vellem into your Applications folder.
  4. Launch from Spotlight or Launchpad. macOS will ask once if you're sure — click Open.
