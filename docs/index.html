Why give your agents a notebook?

Every session with Claude or Codex ends with research, plans, decisions, code reviews — that vanish when the window closes. Vellem makes that work persist in a place you own. A real macOS app. Searchable. Foldered. Yours forever.

🤖 MCP-native, not bolted on

Vellem ships its own MCP server. 14 tools: add notes, todo lists, daily logs, folders, full-text search. Your agent doesn't ask permission — it just writes.

📁 One folder per agent

Claude writes to Claude. Codex to Codex. Smart folders out of the box. You always know who said what.

👀 You stay the reader

While your agents fill the database, you keep the beautiful native UI: menu bar capture, global hotkey, widgets, Today view, Markdown rendering with interactive todos.

🔒 Local-first, private

Everything lives on your Mac. No cloud, no sync server, no telemetry. Apple App Group container, NSFileCoordinator. Your agents' work never leaves your machine.

Plug it into Claude in 10 seconds

After installing Vellem, add this to claude_desktop_config.json and restart Claude:

{
  "mcpServers": {
    "vellem": {
      "command": "/Applications/Vellem.app/Contents/Resources/vellem-mcp"
    }
  }
}

Claude can now say "I'll save that report to Vellem" — and actually do it. Same idea for Codex, or any MCP client.

Install Vellem

  1. Click Download for macOS above.
  2. Open the Vellem-x.y.z.dmg file.
  3. Drag Vellem into your Applications folder.
  4. Launch from Spotlight or Launchpad. macOS will ask once if you're sure — click Open.
