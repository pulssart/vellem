Vellem

A quiet, native macOS notes app with built-in MCP support. Capture fast, organize lightly, connect to anything.

⚡ Fast capture

Global hotkey, menu bar quick capture, Services menu integration. The note is open before you finish thinking.

📐 Folders & smart views

Light organization. Color-tag folders. Daily notes, Today view, Recents — without the friction of a database.

🔌 MCP built in

An MCP server ships in the bundle. Claude, Codex and any MCP client can add, list, search and organize your notes.

🪟 Widgets

Native macOS widgets in all sizes. Your recent notes a glance away on the desktop or Notification Center.

Install

  1. Click Download for macOS above.
  2. Open the Vellem-x.y.z.dmg file.
  3. Drag Vellem into your Applications folder.
  4. Launch from Spotlight or Launchpad. macOS will ask once if you're sure — click Open.
